# 調候用神 (窮通寶鑑 / 欄江網)

> 資料來源：網路公開整理之《窮通寶鑑》調候用神表，程式用資料檔為 `data/tiaohou.json`（**單一真相**）。
> 來源頁面：
> - 《窮通寶鑑》調候用神表（十天干喜用提要）https://www.suanzhun.net/article/1354.html
> - 調候用神實例 附調候用神簡表 https://www.suanzhun.net/article/2248.html
> - 八字-調候用神表 https://m.sohu.com/n/499471970/
> - 輔證：窮通寶鑑-丁火辰月 http://m.8zml.com/h-nd-242.html ；窮通寶鑑-辛金子月 http://m.8zml.com/h-nd-325.html

## 一、定位

調候＝依出生月令的**寒暖燥濕**，取最需要的一味天干來「調節氣候」。
- 冬（亥子丑）嚴寒 → 喜火（丙丁）暖局。
- 夏（巳午未）燥熱 → 喜水（壬癸）潤局。
- 春（寅卯辰）濕寒、秋（申酉戌）燥，各依日干取用。

**用法（本 skill 口徑）**：`yongshen` 以**扶抑為主**（身強弱 `xi/ji`），**調候為輔**（`tiaohou`）。
若命局寒暖偏枯，調候權重提高（余春台《窮通寶鑑》主張調候優先，見來源頁）；無偏枯則以扶抑、格局為主。

## 二、工具如何使用

`bazi_pai.py` 讀 `data/tiaohou.json`，以 `日干 + 月支` 查表，輸出在 `yongshen.tiaohou`：

```json
"tiaohou": { "primary": "丙", "full": ["丙","癸","己"],
             "note": "庚金司令，取丙制之或癸化之，皆己土為佐",
             "source": "窮通寶鑑調候用神表", "key": "乙申" }
```

- `primary`＝第一調候用神（最要緊的一味）。
- `full`＝原表順序全部用神。
- `note`＝原文提要。
- **禁心算**：一律照抄 JSON 的 `primary/full`。

## 四、取用要點（來源頁整理）

1. 調候為急：寒暖偏枯之局，先取調候，格局、身強弱退居其次。
2. 調候用神宜**有根**（支中通根）、**有情**（不被合去、不與日主相礙）。
3. 調候遇沖、克、刑、合未必全凶，但宜避其被破壞。
4. 大運流年逢調候用神為吉；克、泄調候用神者為否。
5. 十神化象：調候用神對日主所成的十神，決定其作用（食神吐秀、正官貴氣…），需與格局合看。

## 五、異文說明

`data/tiaohou.json` 的 `variants` 記錄來源歧異與採納理由，例如：
- `丁辰`：1354 作〔甲庚〕，2248 作〔甲庚戊〕；採〔甲庚戊〕（8zml：木盛用庚，水盛用戊）。
- `辛子`：原表傳抄作〔丙戊壬**申**〕，「申」為地支，係誤抄；採〔丙戊壬〕。
