# 交叉驗證 SOP（定盤 → 命內 → 環境 → 事占）

> 問人、問事都用。**命以命盤為準、事以卦象為準**；多法同向＝可信度高，衝突就講清楚以哪邊為準，別繞圈。
> 這是驗證手法，不是輸出格式；怎麼說見 `shared/output-quality.md`。

## 一、四驗

1. **定盤**：兩盤年月日時是否一致？讀八字 `verification.checks`（真太陽時可逆／時支自洽／大運節氣／納音）與兩盤 `warnings`（跨日、時辰交界、節氣交界）——未過或有值即標低置信。**兩盤時支不一致須退回重定盤。**
2. **命內**：八字 `geju`（月令取格）＋`yongshen`（扶抑＋`tiaohou` 調候）vs 紫微 `patterns`＋四化，方向是否同向？記「一致／衝突」。
3. **環境**：有朝向入住年才查風水（走外部 fengshui skill）；無資料記「未驗」，不腦補。
4. **事占**：只問具體事才起卦；卦中用神旺衰回頭挺／駁命盤結論。

## 二、綜合

- 同向＝加權、可信度高；**衝突＝講清楚兩邊怎麼說、以哪邊為準（說明理由）**，別用「矛盾未解」四個字打發。
- 用了哪幾份排盤、關鍵格局／卦象與出處要講；缺料標「未驗」，不編。

### 問人補充：主盤 × 輔助盤裁決（本 skill 口徑）

1. 總覽題（性格／格局／十年運／大運流年）一律跑 `scripts/person_cast.py`，不得只跑八字或只跑紫微。
2. 定調順序：八字定結構（格局/用神/大運）→ 紫微定象（命宮三方/四化）→ 六壬終身課補一生動態人事 → 奇門終身盤補方位行動。
3. 同向＝加權、可直說；分歧＝**以主盤（八字紫微）為準**，輔助盤作過程/結局/方位註腳，寫清楚兩邊怎麼說。
4. 十年運這類時間窗問題：八字大運＋紫微大限定主節奏，六壬行年＋奇門大限宮用來**核對轉折年份**，四者指向同一年＝高置信。

### 問事補充：六爻／梅花／六壬／奇門打架裁決（本 skill 口徑，非古籍）

1. 先查問句漂移（一事一卦是前提；起卦想 A、解讀扯 B → 重鎖問句，不硬綜合）。
2. 分工：成敗細節聽六爻，方向大勢聽梅花，過程人事／來意／結局聽六壬，**方位／行動／時空調理聽奇門**；四式讀法見 `ask-event/{liuyao,meihua,liuren,qimen}.md`。
3. 純度加權：手搖六爻＞報數梅花＞時間起卦（六壬／奇門同屬時間起課）；皆低純度 → 標低置信，不硬選邊。
4. 同純度真矛盾 → **以六爻為主**（最擅成敗細節），梅花作過程註腳、六壬作過程/結局註腳、奇門作方位/行動註腳；寫分歧＋理由＋置信，不寫「矛盾未解」。
5. 奇門**獨有的方位/行動指引**（往哪個宮的方位走、用哪個門、避哪個宮）即使其他三式不表態，也可單獨給，但標「奇門單邊、中置信」。
6. 只有兩式可比時，仍依「成敗聽六爻、方向聽梅花、過程聽六壬、方位聽奇門」的取向取捨，其餘作佐證。

## 三、敘事建議（參考，不強制）

- 總論：本錢 → 格局 → 大運 → 今年
- 合盤：相遇 → 卡點 → 應期
- 擇日：候選 → 否決理由 → 首選＋備選
- 流年：時間軸走
- 問事：現況（本卦／世應）→ 變數（動爻）→ 結果（變卦）→ 應期
