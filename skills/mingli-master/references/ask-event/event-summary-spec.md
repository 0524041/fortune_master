# 問事摘要說明書（event-summary-spec）

> 用途：問事排盤輸出**怎麼讀**——summary 每行代表什麼、對應哪份知識、何時追加細節。
> 對稱於問人 `zongpan-spec.md`。輸出全走 txt，JSON 僅隱藏除錯不描述。

## 一、summary 逐行解義

第一行 `起卦時間：<時刻>；日柱：<干支>`：
- **基本輸入**：起卦時間預設系統現在（心動即占），日柱是旺衰背景。**不用向使用者要時間**。

六爻行 `六爻：本卦<卦> → <變卦>；動<N>爻；世<N>應<N>`：
- 本卦＝現況，變卦＝趨勢結果，動爻＝變數，世應＝自己與對方/標的。
- 對應知識：`liuyao.md`（SOP）＋`yongshen.md`（用神取法）。細節用 `--only liuyao`。

梅花行 `梅花：本卦<卦>(體<X>用<Y>) → 變<卦>；動<N>爻；<體用關係>(<吉凶>)`：
- 體＝自己，用＝事情；體用生剋＝方向大勢；互卦＝過程、變卦＝結果。
- 對應知識：`meihua.md`（體用五格＋疊加）。細節用 `--only meihua`。

六壬行（`--with liuren` 時才有）`六壬：課體<課體>；初<支><六親> 中<支><六親> 末<支><六親>；月將<支>占時<支>`：
- 三傳＝事的過程起中末；六親＝類神（妻財／官鬼／父母／子孫／兄弟）；課體＝大格局。
- 對應知識：`liuren.md`（12步）＋`liuren-classics.md`（課體取象）。

奇門行（`--with qimen` 時才有）`奇門：<陰陽>遁<N>局；命宮或值符<N>宮(<方>) <門>門<星><神>`：
- 方位/行動指南：門＝途徑吉凶，星＝天時性質，神＝隱情神助。
- 對應知識：`qimen.md`（九宮＋門星神＋吉凶格）。

交叉行 `交叉：日柱<一致/不一致>；警示：<...>`：
- 只記客觀事實（日柱是否一致等），不下吉凶；不一致（換日交界）＝低置信。
- 對應知識：`shared/verification.md` §二問事補充（裁決口徑）。

## 二、預設跑法與追加引導（省 token 契約）

- **預設只跑六爻＋梅花**（易經為主、一成一象互補）→ `event_cast.py --coins ... --numbers ...`。
- **追加六壬**：問「過程人事、來意、人際牽連、結局」→ `--with liuren`。
- **追加奇門**：問「方位、行動方向、時空調理、往哪走」→ `--with qimen`。
- **四式全展開**：交叉題或使用者要求 → `--with liuren qimen` 或 `--only liuyao meihua liuren qimen`。
- 問句未鎖定（一事一問）先讀 `questioning.md` 引導，別急著跑。

## 三、交叉裁決口徑（不變）

- 成敗細節聽六爻，方向大勢聽梅花，過程人事聽六壬，方位行動聽奇門。
- 多式同向＝明說可信度高；分歧＝以六爻為主、他式註腳，寫明理由。
- 六爻手搖（`--coins` 回報）純度最高；其次報數梅花；時間起課最低。
- 卦辭爻辭照抄程式輸出，不編造。

## 四、續問

- 同卦續問細節：`--only <式>` 重取該式全文，**不重起卦**（一事一卦）。
- 換事：重起卦；問題若是長期方向（一生、這五年），轉問人軸。
