# 六爻解卦流程與讀盤指南

> 六爻為主；**梅花易數沿用本檔的解讀要點**（先直答、白話、少反轉），讀盤法另見 `meihua.md`。
> **原理與原書要訣見 `principles.md`**（吉凶悔吝生乎動、動爻為重靜爻為輕）。
> 本檔只教「盤面每個欄位代表什麼、該結合哪些資訊、各領域要回答什麼」；**輸出格式與長短由 agent 自己決定**。

## 一、思考流程 (SOP)

依序走完，每一步結論是下一步依據，形成完整推理鏈：

```
問題檢查 → 盤面分析 → 現實錨定 → 鎖定主角 → 力量評估 → 因果分析 → 時間推算 → 直接回答
 問什麼？   誰在場？   對到現實？  誰重要？   誰強弱？   誰影響誰？ 何時發生？  給人話
```

> 六爻的時間角色是**月建／日辰**（爻的旺衰背景）；卦象來自搖卦（手搖優先，`--coins` 回報；電腦代搖亦可）。**起卦用當下時間，不用另問使用者**。

### 1. 問題檢查 (問什麼)
先抓準用戶真正想知道的（成不成？會不會？何時？），再對應用神（見 `yongshen.md`）。

### 2. 盤面分析 (誰在場)
讀出本卦/變卦、卦宮、世應位置、動爻、伏神、六神。

### 3. 現實錨定 (極重要)
使用者提供的已知事實（腳傷、失業、對象背景等）**先對應卦象說明**，對方才信得過後面。
例：「你提到的腳傷，正對應三爻木被金剋（木為筋），且臨白虎主突發」。

### 4. 鎖定主角 (誰重要)
依問題領域取用神：求財→妻財、事業→官鬼、男問女→妻財、女問男→官鬼、考試→父母、自測病→世爻/官鬼。

### 5. 力量評估 (誰強弱)
- 得月日生扶=旺相；被月日剋洩=休囚。**用神/世爻旺=吉**；**忌神/官鬼旺=阻力大/病情重**（切勿解讀為生命力強）。
- 空亡：旺不為空（假空，填實出空之日應驗）；真空=徹底無望。
- 入墓（辰戌丑未）：被關起來、藏起來、迷糊、受困；需沖開。

### 6. 因果分析 (誰影響誰)
- **先分敵我**：用神＝主角；**原神**＝生用神（幫）、**忌神**＝剋用神（害）、**仇神**＝生忌神（助害）。看誰有力、誰發動。
- 世應關係：世=我、應=對方/環境；相生相合吉，相沖相剋凶。
- 動爻（神兆機於動）：動爻生用神吉、剋用神凶；回頭生/化進神吉，回頭剋/化退神凶。**「動爻為重，靜爻為輕」**。
- 六沖卦主散（問官司災禍久病反而吉）、六合卦主聚（問病訟反而不吉）。
- 「卦不妄成，爻不虛發」：盤面出現的訊號都有意義，不要挑著看。

### 7. 時間推算 (何時發生)
依沖（沖空、沖墓）、合（合住待沖）、填實，或值用神旺相之時推算應期。

### 7b. 無動爻（靜卦）怎麼斷
**沒有動爻 ≠ 沒有訊號。** 依序照斷，仍要給方向與時點：
1. 用神旺衰：得月建／日辰生扶＝有力；受剋洩＝無力。
2. 世應關係：世應生合＝可成；沖剋＝有阻。
3. 墓絕空亡：入墓需沖、空亡待填實、絕地待生扶。
4. 應期：靜卦以「沖、合、填實、值日值月」對用神取時點。
只有「六爻亂動無章法、問題又模糊」才可判心神未定，建議靜心重卦。

### 8. 直接回答
把上面的推理翻成**人話，先回答用戶問的那一句**（見下「解讀要點」）。

## 二、解讀要點（怎麼說）

**先分題型，再決定講什麼：**
- **成敗題**（能不能成／會不會）→ 用神旺衰、世應生剋為主。
- **時機題**（何時）→ 應期（沖合填實、值用神）為主。
- **取象題**（會遇到什麼／有哪些細節）→ 六親六神、互變、卦象取**具體畫面**，不能只給氛圍（見第 9 條）。

1. **先直答**：第一句直接回答用戶問的那句（成/不成、吉/凶、會不會、何時），論證放後面。
2. **白話優先**：術語放括號補充，別整段術語。少用「用神、忌神、世應」當句子的主詞。
3. **拒巴納姆**：講具體（誰、什麼事、往哪走）；不講「運勢有阻礙」這類換誰都成立的話。凶就直說。
4. **少反轉、置信分級**：定了調就別再「但如果…」「也不排除…」自我推翻；或然判斷帶置信標記（高／中／低置信）——無標記的「可能／也許／大概／較像」不寫，要嘛斷，要嘛寫「這條看不出來」。真沒把握的，**單獨一條**說「這條我看不準」，不要寫成整段但書。
5. **大凶直言**：健康大凶（官鬼旺相、用神真空入墓）直說「情況不樂觀」，不用「生命力強」粉飾。
6. **卦義以盤面為準**：卦辭/象傳/諸事/爻辭照盤面引用，不編造。
7. **動爻爻辭照抄**：盤面【動爻爻辭】已附《周易正義》爻辭，直接引用，不憑記憶。
8. **卦象脫節**：六爻亂動無章法且問題模糊 → 直說心神未定、建議重卦；否則照斷，勿輕易放棄。
9. **取象要具體**（問「會遇到什麼」時）：用六親取人事——子孫＝飲食玩樂、父母＝場所/訊息/長輩、兄弟＝第三人/分帳、官鬼＝壓力/病/官方、妻財＝錢/女方；六神取味道（青龍喜、朱雀口舌、白虎急、玄武暗昧、螣蛇反覆、勾陳拖延）；動爻與互變取插曲與過程。真的取不出具體象才寫「無特別事件，順順過」，不要用氛圍話填空。
10. **兩法交叉要綜合**：六爻＋梅花（＋六壬＋奇門）同向＝明說「多法一致、可信度較高」；分歧＝說「以哪個為主、為什麼」。四式分工與裁決見 `liuren.md` 第七、八節、`qimen.md` 第八節與 `references/shared/verification.md`。

## 二b、推理自檢與說過程（自檢為主＋邀核對）

- **自檢五段**（輸出前逐段勾，不許跳）：問句複述 → 用神選定（決策樹第幾條）→ 旺衰評估 → 動變分析 → 結論應期置信。
- **說過程**（給使用者）：每條斷語附一句「怎麼看出」（卦象白話翻譯）；結尾邀核對：「以上哪條跟你知道的不符，直接說，我重看。」——讓使用者能揪推理錯誤或誤會。

## 三、盤面欄位意義（這些資訊代表什麼）

| 欄位 | 代表什麼 | 怎麼用 |
|---|---|---|
| 本卦 | 當下處境 | 事情現在的樣貌 |
| 變卦（之卦） | 結果/趨勢 | 事情往哪走；無變卦＝現況延續 |
| 卦宮（八宮） | 六親的基準五行 | 決定六親怎麼安 |
| 世爻 / 應爻 | 我 / 對方（環境） | 生合吉、沖剋凶；看誰主動誰被動 |
| 用神 | 這題的主角（依領域取） | 旺衰定吉凶；見 `yongshen.md` |
| 動爻 → 變爻 | 事情的變數（神兆機於動） | 生剋用神定吉凶；化進/化退、回頭生/剋 |
| 伏神 | 本卦缺的六親（藏著） | 用神伏藏＝事未現、待引出；飛伏生剋 |
| 六神（青龍…朱雀…） | 事情的味道/細節 | 白虎血光、螣蛇驚恐、玄武暗昧、朱雀口舌、青龍喜慶、勾陳遲滯 |
| 月建 / 日辰 | 旺衰的來源（環境與時機） | 生扶＝有力、剋洩＝無力；日辰能沖起/合住 |
| 空亡 / 入墓 | 有無 / 受困 | 空＝虛、待填實；墓＝困住、待沖開 |
| 神煞（驛馬/桃花/祿/貴人） | 點綴性訊號 | 輔助定位，不主斷（見 `references/shared/glossary.md`） |
| 動爻爻辭 | 《周易正義》該爻原文 | 佐證動爻吉凶，照抄不編 |

## 四、各領域該回答什麼（先答用戶最想知道的）

| 領域 | 用戶真正想知道 | 主力用神 | 一定要答到 |
|---|---|---|---|
| 感情/婚姻 | 有沒有結果、對方心意 | 男問女→妻財；女問男→官鬼；再合世應 | 成不成、對方態度、何時 |
| 日常事（約會／聚餐／出門） | 順不順、會遇到什麼 | 依事取：見面→對方；飲食→子孫；場所→父母 | 具體畫面與插曲（見第 9 條） |
| 事業/工作 | 上不上、會不會動 | 官鬼、父母 | 成敗、時間、該做什麼 |
| 財運/投資（起卦） | 進財時機、該不該進出 | 妻財、子孫、兄弟 | 時機、方向（不替人下單） |
| 考試/學業 | 上不上、名次 | 父母、官鬼 | 成敗、名次 |
| 健康 | 輕重、走向 | 世爻/官鬼、子孫 | 趨勢與用藥方向 |
| 失物/尋人 | 找不找得到、在哪 | 妻財/子孫、應爻 | 能否尋回、方位 |
| 官司/糾紛 | 勝負、宜和宜訟 | 官鬼、父母 | 勝敗、建議和或爭 |

> 用神完整對照表見 `yongshen.md`；六親/六神含義亦在該檔。

## 五、引導檢查點（起卦前三道門，不過門不起卦）

- **門1 用神選定句**：起卦前必須寫出「此問取 X 為用神，因為…（決策樹第 N 條）」。寫不出 → 不許起卦。
- **門2 澄清兩問**：具體什麼事？涉及誰？問不出 → 轉世爻為用法＋標低置信，並明示用戶（例：「你沒說具體事，我以世爻代表你本人看順不順，置信低」）。
- **門3 現實錨定料**：至少一條已知事實（處境／時間／對象）；全無 → 結論只給方向＋低置信。
