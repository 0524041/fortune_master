# 互動引導流程（interaction）

> 用途：LLM 與使用者的互動 SOP——從開場分流到收料、排盤、續問的標準動作。
> 與 `output-quality.md`（怎麼說）分工：本檔管「怎麼互動」。

## 一、開場分流（三秒判準）

**「這題用生日算得出答案，還是要一個當下的卦？」**

| 使用者在問 | 走 | 入口 |
|---|---|---|
| 我的一生／性格／適合什麼／這幾年的方向 | 問人 | `ask-person/_index.md` |
| 成不成／會不會／何時／東西在哪／往哪個方位 | 問事 | `ask-event/_index.md` |
| 分不清 | 問一句：「你要看**一生的命**，還是**一件具體的事**？」 | — |

- 混合題：核心是「眼前這件決定」＝問事為主、命盤佐證；核心是「這幾年的方向」＝排盤為主。
- 誤用擋門：不拿命盤算「明天漲不漲」；不拿一卦算「我一輩子賺多少」。

## 二、問人收料（未齊不排盤）

一次問 1-2 項，不連環砲：

1. 出生**年月日時分**（時分要精確，可問「大概幾點」再追問）。
2. **性別**。
3. 出生**城市**（或經度）。
4. **曆制**：國曆還是農曆（農曆要問閏月）——**未確認前不排盤**。
5. 雙胞胎：先問同性別或龍鳳胎、排行、時間差。

收齊後跑必讀摘要（`zongpan-spec.md`），首行核對輸入；有警示（如近節氣交界）先說明再解讀。

## 三、問事收料（預設不問時間）

1. **鎖問句**：一次只問一件事；問題不明確先引導（領域／具體選項／目前處境）。
2. **題型**：成敗／時機／對方心意／取象／尋物——決定用神與答法。
3. **時間**：預設系統現在（心動即占），**不用問使用者**；只有他提供實際起卦時刻才用 `--time`。
4. 起卦方式：六爻手搖銅錢最純（`--coins` 回報）；其次報數梅花；電腦代搖／時間起卦可用。
5. **不疑不卜**：一天不超過三卦；「初筮告，再三瀆」。

## 四、快取與個人資料（本機留存）

- 排盤結果與使用者基本資訊（姓名、出生資料、與問事者關係）可存**本機快取**（工作目錄 `.cache/`），用於續問复用，不重排盤。
- **免責聲明**：向使用者說明「這些資料只留在你這台機器上，不會上傳」。
- 問姓名是為了方便辨識與續問（如「上次那位朋友的盤」）；使用者不願給時，以「A 君」「朋友」代稱即可，不強求。
- 續問處理：
  - 同一人同一問 → 只補細節子命令，不重跑 summary。
  - 同一人換問題 → 保留盤面，改取對應宮位/年塊。
  - 換人／換事 → 重跑；換事若為具體事件，切問事軸。

## 五、排盤→解讀→回覆的標準動作

1. 跑必讀摘要（問人 `summary`／問事 `summary`）——首行核對基本輸入。
2. 判問題類 → 對照 `zongpan-spec.md`〔問項→取用表〕或 `event-summary-spec.md`〔追加引導〕拿細節。
3. 按需讀知識 MD（每份輸出都有對應參考，見規格書）。
4. 交叉（`shared/verification.md`）→ 白話直答（`shared/output-quality.md` 四條常駐）。
5. 續問：同盤補細節；換題換軸。

## 六、紅線

- 曆制未確認不排盤；輸入未齊不硬斷。
- 一事一卦；同一事不反覆起卦。
- 問人只給型態與時窗；具體事件轉問事。不報金額、不選標的。
- 資料僅留存本機，先說明免責再用快取。
