# 財運解讀 SOP (來源 → 守財 → 應期)

> 財運不是一個宮的事。先分三問，再交叉八字與紫微；數據以排盤 JSON 為準，禁心算、禁編金額。
> 解讀要點見 `references/shared/output-quality.md`（先直答、掛依據、能給應期就給）。

## 〇、先分清問的是哪一種「財運」

| 問法 | 看什麼 | 這題在問 |
|---|---|---|
| 「我能不能賺到錢／財從哪來」 | 財帛宮＋官祿宮＋財星用神 | **來源**（主動收入 vs 投資/偏財） |
| 「錢守不守得住／會不會漏」 | 田宅宮（庫）＋福德宮＋比劫 | **守財**（存得下 vs 過路財神） |
| 「今年／這幾年財運／何時進財」 | 大限＋流年／流月疊財帛、田宅、官祿 | **應期**（進財/破財時間窗） |

問得籠統時，**先把題縮到其中一問**再答；三題混成一團，答案一定變巴納姆。

## 一、紫微：財務四宮＋財星

- **財帛宮**：求財方式與現金流性格。主星決定「怎麼賺」——武曲（金融/務實/硬技術財）、天府（守成/庫房/穩定）、太陰（田產/租金/細水長流）、貪狼（業務/偏財/應酬財）、廉貞（合作/行政財）、破軍（大起大落）。
- **田宅宮**：資產與「庫」。田宅旺＝存得下；見忌/空劫＝財來財去、住居耗財。
- **官祿宮**：事業帶來的收入。喜化權（掌權）、化祿（進帳）。
- **福德宮**：理財心態與慾望。福德忌＋煞＝想得多、易賭一把、易衝動。
- **三方四正**：財帛的三方（命、官、遷）有無祿、權、祿存；見忌/煞＝破口先修那裡。
- **四化落點**：化祿落財帛/田宅＝進財有庫；落官祿＝事業財；化忌落財帛/田宅＝破財點。

## 二、八字：日主能不能任財

- **財為用或忌**（讀 `yongshen.xi/ji`）：身強任財＝財星為用，走財運得力；身弱財旺＝見財反累（看得忙、賺不到、為錢所困）。
- **生財路徑**：食傷生財＝靠才華/作品/技術換錢；比劫奪財＝合夥同儕分利，需白紙黑字；印剋食傷＝想太多動不了。
- **財星狀態**：財星入墓、逢沖、被合＝財被卡住/被別人拿走/財星動。
- **大運流年**：逢財星到位且為用＝進財窗；逢比劫/沖財＝破財、拆帳、別合夥。

## 三、交叉驗證（以 `cast.py` 語義初判為準，LLM 覆核）

- 先讀 `caiyun_semantic`：`verdict`（同向／分歧／單邊／缺料）＋`kind`（進財窗／守財）＋`reasons`。
  - 同向＝財運窗或守財，直接肯定講。
  - 分歧＝結論偏保守，仍給型態與時窗（寫明兩側各自依據）。
  - 單邊＝僅一側表態；缺料＝此題不斷財運，寫「這條我看不準」。
- 不寫「矛盾未解」四字打發；必須選邊＋理由；低把握才說明不確定的原因。
- 流年財帛宮落本命哪一宮、主星為何 → 決定「今年財運主戰場」。

## 四、轉譯規則（宮星 → 判斷 → 動作）

每個判斷都要落成「現金流型態＋可執行動作」：

| 盤面 | 判斷 | 動作 |
|---|---|---|
| 天府＋右弼坐流年財帛 | 守成、有貴人幫，穩定累積 | 定期定額；年終獎金先鎖一半 |
| 地空同宮 | 錢易來易去、突發支出 | 留 6 個月現金流，別押單一標的 |
| 太陰化祿入田宅 | 住居/置產支出增加，有庫 | 有買房計畫今年可談，先算好月付 |
| 巨門化忌壓財帛 | 為錢/口舌糾紛 | 借貸與合約白紙黑字，別當保人 |
| 八字比劫旺逢財 | 合夥分利 | 別合夥；要合先把出資與分潤寫死 |

## 五、紅線

1. **不報金額、不報投報率、不選個股/標的**——命盤給的是「型態與時窗」，不是數字。
2. 沒有盤面依據的財運預測不寫；寧可寫「這條我看不準」。
