# 命盤／流年輸出模板 (結論先行、每句可驗證或可執行)

> 問命（八字／紫微、流年運限、財運/事業/感情/健康）走這份；問事起卦（六爻／梅花）走 `references/yijing/interpretation.md`。
> 目標：**禁止「講了跟沒講一樣」**。謹慎不是空泛的藉口：有依據就直說方向，沒把握就明寫「這條我看不準」。

## 一、五段式 (順序口氣自由，內容不可缺)

1. **定調**：第一句直接給結論（成/不成、吉/凶、偏哪一邊）。不准用「需注意」「視情況」「因人而異」開場。
2. **依據**：每個結論掛「宮位＋主星/四化」或「干支＋十神/用神」，並註明是哪份排盤得出。
3. **應期**：給時間窗（哪個大限／流年／流月，或節氣／月份）。真的推不出才寫「這條我看不準」，不准留白或寫「未來某時」。
4. **動作**：至少一條「該做」＋一條「不該做」，用動詞開頭（例：把年終先鎖一半、別當保人、合約白紙黑字）。
5. **翻轉條件**：寫明什麼情況此結論失效（例：改立春分界則流年宮位移、出生時辰差一刻鐘則重排）。

## 二、反巴納姆禁令 (硬性)

下列句型一律視為未過關，必須改寫成「具體命理依據＋具體後果」：

| 空泛寫法 (NG) | 具體改寫 (OK) |
|---|---|
| 重點偏向累積與管理 | 天府坐財帛主守成：錢要靠「存下來」變多，不是靠一波賺；走定期定額，不追高 |
| 要確認投入是否換成實際報酬 | 財帛見地空，錢易來易去：先壓住固定支出，別押單一標的 |
| 不代表一定買房 | 太陰化祿入田宅：住居相關支出今年增加（裝修/換約/頭期），是支出訊號不是獲利訊號 |
| 運勢有阻礙 | 巨門化忌壓財帛：為錢或為話起爭執，借貸與合約先白紙黑字 |
| 因人而異／視情況而定／可能也許大概 | 刪掉；改成你判定的那一邊，或明寫「這條我看不準」 |

**判準**：把主詞換成別人還成立（誰都適用），那句就是巴納姆，退貨重寫。

## 三、長度與取捨

- 一個問題 3–6 段，先講最重要那條，不必逐宮報帳。
- 星曜只講對這個問題有作用的那幾顆，其餘略過。
- 財運題另見 `references/methods/caiyun.md`（來源→守財→應期）。
- 免責只在六爻問投資時出現；命盤／流年題不挾帶「不構成投資建議」。
