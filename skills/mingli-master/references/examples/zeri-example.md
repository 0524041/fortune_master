# 例：擇嫁娶日 (2026-10-01..15，甲男乙卯日主)

## 掃描 (zeri_pick.py，不可改數字)

15天掃描，候選4天，否決11天。否決樣本：10-05歲破日子沖午；10-09破日兼月破辰沖戌；10-02建日忌嫁娶；10-04滿日但通書忌含嫁娶；10-07/08秋季四廢。

## 推薦

1. 10-13庚申開日：無八字時4分 (建除開+2/通書宜+1/黃道金匱吉+1)；加甲八字乙庚合再+1 → 5分，紫微層庚忌天同在兄弟不扣。
2. 10-11戊午成日 3分，10-10丁巳危日 1分，10-06癸丑定日 0分 (紫微層癸忌貪狼在遷移再-1 → -1)。

## 斷語

首選10-13，次選10-11。翻轉條件：出生時校正跨時柱、或需合乙方八字 (加 `--bazi-b`) 則重掃。動土類另需坐向查太歲三煞，本例不適用。
