# 大運流年作用與應期 (知識層；排盤數字以 bazi_pai.py JSON 為準)

> 4-1、4-2 可入庫（5–6 源）；填實／墓庫開合／空亡出空待定，見末節。

## 一、體用

- 命局靜為體（定層次格局，不被歲運改變）；大運流年動為用。
- 大運管十年趨勢（為流動月令）；流年管一年，為應期觸發器。
- 原局有象 → 大運引動 → 流年兌現。吉凶看歲運生扶／沖剋用神、合去忌神。
- 大運好流年凶，以吉斷；大運凶流年吉，仍以凶論。
- 補充規則（單系，降級用）：大運空亡時流年可越過大運直斷命局。

## 二、引動應期

- 天剋地沖、一支沖三支、羊刃逢沖、傷官沖官、日支為刃逢沖：多主凶（破耗血光子息不安）。
- 桃花逢沖：主喜／感情動。合：絆住喜忌。
- 念鮮口訣：運逢反吟非破耗血光則子息難安；傷官逢刑沖非官符則病耗。

## 三、待定（不作斷語依據）

- 填實（空亡待歲運填實發用）：僅 3 源。
- 墓庫開合：實 1 源；「逢庫必沖開」已被《子平真詮評注》斥為謬論，不采。
- 空亡出空／三空斷生死：3 源且互斥，門派極雜；年空能否填實僅一家之言。
