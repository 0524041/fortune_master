# 雙胞胎／多胞胎處理（同辰異命）

> 使用者提到「雙胞胎、龍鳳胎、我跟我弟／妹」時先讀這份。
> 同年月日時 → 同一張盤；但先天只占 1/3，後天（環境、姓名、選擇）占 2/3，所以兩人命運會分開。
> **兩派方法不可混用**：先說明你用哪一派，一路走完。

## 一、先問清（一次 1–2 題）

- **同性別還是龍鳳胎**？（龍鳳胎不調盤）
- **排行**：老大／老二／老三？
- **出生時間差**？是否跨時辰（幾分鐘 vs 一小時以上）？

## 二、怎麼處理（依體系）

| 情況／體系 | 方法 | 指令 |
|---|---|---|
| **龍鳳胎** | **不調盤**。同一張盤，男女大運／大限順逆相反，自然分化 | 各以 `--gender male/female` 正常排 |
| **同性・紫微南派（預設）** | **借宮立極**：星曜不動，十二宮名旋轉——老二借「兄弟宮」為命宮、老三借「夫妻宮」…；大限自新命宮起 | `cast.py --twin-order N`（紫微預設 rebase） |
| **同性・紫微（時辰遞推）** | 生時進一位、**整盤重算**（部分南派學者）；命宮同樣落到原兄弟宮，但星曜會移動 | `cast.py --twin-order N --twin-ziwei shift` |
| **同性・紫微北派** | **同盤異用**：不改盤；老二以兄弟宮為「立極」切入，看四化飛星路線與應期差異 | `cast.py --twin-order N --twin-ziwei none` |
| **八字（子平法）** | **時柱進一位**（如丙午時→丁未時）；年／月／日柱與大運不變 | `cast.py --twin-order N`（八字自動） |

## 三、腳本已處理的細節與限制

- **借宮立極**：星曜與宮干**留在原支不動**；只旋轉十二宮名與 `ming.branch`；大限重新錨定到新命宮、**沿用原局起運歲**；**身宮支不動**。
- 借宮後**格局與運限仍以原命宮判定**，僅供參考；搭配 `--at` 時變盤會移除運限並提示需重排。
- **時辰遞推**：整盤重算（命宮／身宮／五行局／星曜／大限全變）；與借宮立極結果不同，別混用。
- **八字時柱進位**：年／月／日柱與大運不變；校驗欄會標「不與真實時支比對」。**晚子時（23:00–24:00）與需跨兩日者暫不支援**（腳本會報錯，改用紫微借宮）。
- **三胞胎**：`--twin-order 3`（紫微借宮再進一位；八字視時辰可能不支援）。

## 四、解讀提醒

- 先說你用**哪一派**（南派借宮／北派同盤／時辰遞推／子平時柱進位），別中途換。
- 兩人的差異要講在**後天**：姓名、房間方位、交友圈、重大選擇順序；命盤只給趨勢。
- 排行影響：老大用原盤；老二以上用相應變盤（借宮或進位）。

## 五、六壬／奇門 雙胞胎（輔助盤，權重低）

> 六壬、奇門都是「一事一課／一局」的問事法，雙胞胎**同刻 → 同課同局**。它們各有古法區分，但都只是**輔助盤**，雙胞胎的定論仍以**主盤（八字時柱進位／紫微借宮）**為準。

**六壬（終身課）**
- 同課時，古法用**次客法**（換將不換時）區分：陰將二客＝前五、陽將二客＝後三（`liuren.py --lifetime --twin 2`）。但邵彥和已自承「次客換將**多不驗**」，主張**以各人年命為主**（「課雖同而理則異」）。
- 因此：**龍鳳胎**→行年順逆不同，可用年命區分（高置信）；**同卵同性同命**→六壬**不可分**，次客法僅備用且標**低置信**，實務改依主盤。

**奇門（終身盤）**
- 奇門有**原生**區分法：**六親宮**——**日干落宮＝本人、月干落宮＝兄弟**（《奇門遁甲元靈經》「月干兄弟……欲分兄弟，照日月支干看宮分內外」）。雙胞胎比較**兄弟宮與本人宮**的**內外盤、生剋、八門九星八神**，即可分象。
- `qimen.py --lifetime` 已輸出六親宮（父/母/兄弟/本人/子女）；看兄弟宮與本人宮是否**一內一外**（分居/分立）、**相生相剋**（相親/相爭）。

**取捨**：雙胞胎主用主盤；六壬／奇門的區分**當佐證**——奇門兄弟宮（原生、較可靠）＞六壬年命（龍鳳胎可用）＞六壬次客（低置信）。
