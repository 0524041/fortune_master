# 奇門遁甲解盤流程與讀盤指南（問事）

> 奇門與六爻、梅花、六壬**同屬問事軸**（看當下起局，一事一局）。以局象為準。
> 起局與讀盤由 `qimen.py`（單盤）／`event_cast.py`（四式合盤）產生，**算數不心算**。
> 流派：**拆補法定局、轉盤、陽盤（節氣陰陽遁）**；文獻《奇門遁甲統宗》《奇門遁甲元靈經》《奇門法竅》。

## 一、起局（拆補法）

1. **四柱**：以起局時刻（**終身盤用真太陽時**；時盤用當地時鐘）。
2. **陰陽遁**：冬至後用**陽遁**、夏至後用**陰遁**（以節氣分）。
3. **定元**：由**日干支的符頭**（最近的甲/己日）定三元——符頭支子午卯酉＝上元、寅申巳亥＝中元、辰戌丑未＝下元。
4. **定局**：節氣＋三元 → 局數（拆補法表，陽遁 174、陰遁 936 各節氣輪）。
5. **布地盤三奇六儀**：陽遁自局數宮**順布**、陰遁**逆布**，序為「戊己庚辛壬癸丁丙乙」。
6. **定值符值使**：時干支的**旬首**（甲子戊/甲戌己/甲申庚/甲午辛/甲辰壬/甲寅癸）所落之宮＝值符宮；該宮固定九星＝**值符**、固定八門＝**值使**。
7. **轉天盤**：「值符隨時干」——值符星移到**時干所落之宮**，其餘八星、八干隨之旋轉（轉盤）。
8. **布八門**：「值使隨時宮」——值使門自旬首宮依時支數（陽順陰逆）移位，八門隨之旋轉。
9. **布八神**：「小值符隨大值符」——值符神落在值符星之宮，其餘七神陽順陰逆排於八宮。

**子時換日**：奇門採 23:00 起算次日（與六爻/六壬的午夜換日不同，見交叉警示）。

## 二、讀局 SOP（依序走完）

```
問題檢查 → 定用神 → 用神落宮 → 門星神干 → 旺衰 → 格局 → 生剋 → 應期 → 直接回答
 問什麼？   誰代表？   在哪裡？    四盤組合？  有力嗎？  吉凶格？  誰剋誰？  何時？   給人話
```

1. **問題檢查**：抓準真正想問的（成敗／時機／對方心意／取象／東西在哪）。一次一事。
2. **定用神**：依領域取**用神**（見第五節），用神＝這件事在盤上的代表符號。
3. **用神落宮**：看它落在哪一宮——**宮＝環境與方位**（見第四節九宮象意）。
4. **門星神干（四盤合看）**：該宮的**八門（人事/途徑）＋九星（天時/性質）＋八神（神助/隱情）＋天地盤干（格局）**，四者合參。
5. **旺衰**：以月令論九星、八門、天干的**旺相休囚**（同六壬「旺相死囚休」）；用神旺相＝有力。
6. **格局**：看**吉格**（三奇得使、三遁、玉女守門…）與**凶格**（六儀擊刑、門迫、伏吟反吟、大格、五不遇時…）；凶格所在即阻力所在。
7. **生剋**：用神宮 vs 日干宮（我）／時干宮（事）；宮門生剋（門迫＝門剋宮，制＝宮剋門）。
8. **應期**：用神宮所值之支／馬星／值使宮；近遠看內外盤。
9. **直接回答**：翻成人話，先回用戶問的那句。

## 六、八門・九星・八神（性質與吉凶）

**八門（人盤）**：開（金/吉，開創謁貴）、休（水/吉，安穩婚戀）、生（土/吉，生財產業）＝三吉門；死（土/凶，死喪田土）、驚（金/凶，驚恐口舌官非）、傷（木/凶，爭鬥捕獵）＝三凶門；杜（木/平，閉塞躲藏）、景（火/平，文書訊息遠行）＝平門。

**九星（天盤）**：天輔·天禽·天心·天任＝吉；天蓬·天芮·天柱·天英＝凶；天冲＝小吉。（蓬盜水險、芮疾病、冲衝動、輔文教、禽中正、心醫謀、柱口舌破壞、任田產、英文采虛華。）

**八神（神盤）**：值符（貴人主帥）、太陰（陰助女人）、六合（和合婚姻）、九地（厚重守成）、九天（高遠揚名）＝吉；螣蛇（虛驚反覆）、白虎（凶傷爭鬥）、玄武（盜賊暗昧）＝凶。

## 七、吉格・凶格（選要）

**吉格**：**三奇得使**（乙丙丁臨三吉門）、**三遁**（天遁：丙+生門；地遁：乙+開門；人遁：丁+休門）、**玉女守門**（丁奇臨值使門）、**青龍返首**（戊+丙）、**飛鳥跌穴**（丙+戊）、**青龍合靈**（戊+乙）、**奇儀順遂**（乙+丙）、**五神互合**（丁+壬）、**小蛇化龍**（壬+戊）、**天乙會合**（癸+戊）。

**凶格**：**六儀擊刑**（甲子戊落震3、甲戌己落坤2、甲申庚落艮8、甲午辛落離9、甲辰壬落巽4、甲寅癸落巽4）、**門迫**（門剋宮）、**伏吟**（天盤=地盤）、**反吟**（八門加對沖宮）、**五不遇時**（時干剋日干，同陰陽；如甲日庚午時）、**天網四張**（時干癸）、**三奇入墓**（乙丙墓乾6、丁墓艮8）、**六儀入墓**（戊6己庚8辛壬4癸2）、**八門入墓**（休生死4、傷杜2、景6、驚開8）、**大格**（庚+癸）、**小格**（庚+壬）、**刑格**（庚+己）、**太白同宮**（庚+庚）、**熒入太白**（丙+庚）、**太白入熒**（庚+丙）、**青龍逃走**（乙+辛）、**白虎猖狂**（辛+乙）、**朱雀投江**（丁+癸）、**螣蛇夭矯**（癸+丁）、**白虎干格**（庚+辛）、**值符飛宮**（戊+庚）、**火入天羅**（丙+壬）。

**十干克應**（天盤干＋地盤干，共 9×9＝81 格）：每宮天盤干壓地盤干即成一格，是奇門最細的細節層；程式逐宮輸出（如「大格[庚+癸·凶]」）。同名格有流派差異，以生剋與門星旺衰為準，勿單憑格名。

**門迫 vs 制和義比**：門剋宮＝**迫**（凶）；宮剋門＝**制**；宮生門＝**和**；門生宮＝**義**；同＝**比**。**宮制其門不為迫，門制其宮是迫雄**（《奇門法竅》）。

## 八、與其他問事法的分工

| 取向 | 主用 |
|---|---|
| 具體成敗、時間、細節 | 六爻 |
| 方向大勢、觸機、象義 | 梅花 |
| 過程人事、來意、結局 | 六壬 |
| **方位、行動、時空調理、擇方** | **奇門**（九宮＋八門） |

四式同向＝高置信；分歧裁決見 `references/shared/verification.md`。奇門**獨有**的是**方位與行動指引**（該往哪個方位、用哪個門、避哪個宮）——這是六爻/梅花/六壬沒有的維度。

## 九、輸出品質（引 `references/shared/output-quality.md`）

- **先直答**：第一句回答用戶問的那句。
- **每句掛依據**：用神宮/八門/九星/八神/格局。
- **能給應期就給**：用神宮支、馬星、值使宮；內外盤定快慢。
- **取象具體**：門星神干合取畫面（「生門臨戊＝有本錢的財路」），不給氛圍話。
- **給方向**：奇門的價值在**方位與行動**——講清楚往哪個宮的方位走、用哪個門、避哪個宮。
- **結果怎麼講**：四式同向直接肯定；單一依據（如奇門單邊）說明不確定的原因；孤證標低把握。
