# 大六壬解課流程與讀盤指南

> 六壬與六爻、梅花**同屬問事軸**（看當下起課，一事一課），不是算命。以課象為準。
> 起課與讀盤由 `liuren.py`（單盤）／`event_cast.py`（四式合盤）產生，**算數不心算**。
> 原理見 `principles.md`；輸出腔調見 `references/shared/output-quality.md`；四式分工與矛盾裁決見 `references/shared/verification.md`。

## 一、起課（月將加占時）

- **起課即「心動」那一刻**，用**當地時鐘**當下時間，不做真太陽時校正（真太陽時是八字用的）。使用者提供實際起課時刻才用 `--time`。
- **月將**：以**中氣換將**（雨水後登明亥、春分後河魁戌…冬至後大吉丑、大寒後神后子）。程式自動以節氣定。
- **天盤**：把月將壓到占時之上（「月將加時」），旋出十二宮天盤。
- **局**：第 n 局 =（占時−月將）mod 12 + 1。
- **晝夜**：卯至申為晝，酉至寅為夜；決定取晝貴或夜貴布十二天將。
- **年命**：可選輸入問事人（主客二人上限）出生年＋性別，算**本命／行年**入盤看落點。**年命只是佐證**，六壬主體是四課三傳，不是命盤。

## 二、讀課 SOP（依序走完，每步結論是下一步依據）

```
問題檢查 → 定四課三傳 → 現實錨定 → 鎖定類神 → 力量評估 → 因果鏈 → 天將著色 → 應期 → 直接回答
 問什麼？     課怎麼起？    對到現實？   誰是主角？   誰強誰弱？  誰生誰剋？  味道細節？  何時？   給人話
```

1. **問題檢查**：先抓準真正想問的（成敗／時機／對方心意／取象／東西在哪）。一次一事。
2. **定四課三傳**：程式已算好。看**三傳**（初=發端／現在、中=過程、末=結果）與**四課**（干上=我、干陰=我之暗、支上=事體/對方、支陰）。
3. **干支分局（主客先定）**：**干＝我／身／此處／問事人；支＝事／彼／所求之人／任所／宅**（求官干為求官人、支為任所；謀財干為我、支為所求之人）。先省干支上神，再看三傳。
4. **現實錨定（極重要）**：把使用者已知事實先對上課象（例：問腳傷，見白虎臨三傳／申酉金剋木），對方才信得過後面。
5. **鎖定類神**：依領域取**類神**（第五節），看它在四課三傳的**旺衰、空亡、墓、天將**。
6. **力量評估（月令五氣）**：類神旺相＝有力、死囚休＝無力（旺相死囚休見盤面「月令五氣」行；所勝所憂：旺→縣官、相→財物、死→死喪、囚→囚系、休→疾病）。**空亡**＝落空未實（旺不為空，出旬填實則應）；**入墓**（辰戌丑未）＝受困，待沖。
7. **因果鏈（生剋・內外戰）**：類神（主角）→ **生類神者**（原神，助力）→ **剋類神者**（忌神，阻力）→ **三傳相生則吉、相剋則凶**；**神剋將為內戰（禍難解）、將剋神為外戰（禍微易解）**；干（我）與支（事/彼）生剋刑沖合害。
8. **天將著色**：吉將（貴、龍、常、合、后、陰）加力；凶將（蛇、雀、勾、空、虎、玄）添憂；同一支五行生剋定吉凶，天將定細節（第七節）。**天將只調味，不主生剋**。
9. **上下剋的指向**：上剋下＝憂他人、事起男子（客勝主人，宜客宜行）；下賊上＝憂己身、事起女人（主勝客，宜主宜守）。
10. **年命切己**：三傳為大概之象，**年命方切己**；命上吉神吉將＝事歸於己，命入空死墓＝己身受損。
11. **應期**：依三傳地支取**值日、沖、合、填實（空亡）、沖墓**之時，或用**河魁加時相乘**法、**歲月日時為期**（見 `liuren-classics.md` 第八節）。
12. **直接回答**：翻成人話，先回用戶問的那句。

> 以上邏輯鏈的古籍出處與延伸（十二天將旺衰斷、十二月將主事、三十六課體、取象派心法、主客與多人同占）見 `liuren-classics.md`。

## 三、盤面欄位意義

| 欄位 | 代表什麼 | 怎麼用 |
|---|---|---|
| 四柱（年月日時） | 起課時空座標 | 日干=求測者；日支=事體/對方；月將=太陽所在（天時） |
| 月將 / 占時 / 局 | 天地盤怎麼旋 | 天時、來意；決定天地盤 |
| 天地盤 | 「天盤加地盤」十二宮 | 天盤=神（外來、上層、變化）；地盤=位（本方、下層、本質） |
| 四課（上下神） | 一課干上、二課干陰、三課支上、四課支陰 | 干＝我、支＝事/彼；上神為現在、陰神為內在 |
| 三傳（初/中/末） | 事情的發端→過程→結果 | **初傳＝事情關鍵/發用**；末傳＝結局 |
| 十二天將 | 事情的性質與味道 | 吉將助吉、凶將添凶；見第七節對照 |
| 遁干 | 各支所配天干 | 定十神、看更細的因果 |
| 六親（父母/兄弟/子孫/妻財/官鬼） | 類神的五行角色 | 依日干取；判生剋鏈 |
| 旬空 | 空亡（天盤空／陷空） | 落空、虛、未實；填實或出旬則應 |
| 神煞 | 點綴性訊號 | 驛馬（動）、桃花（情）、日祿（財祿）、羊刃（血光）、天醫（藥）、月破（破壞）…輔助定位，**不主斷** |
| 月令五氣（旺相死囚休） | 月令的五行盛衰 | 類神在旺相＝有力、死囚休＝無力；所勝所憂：旺→縣官、相→財物、死→死喪、囚→囚系、休→疾病 |
| 課體（課名） | 課的格局類型 | 賊克/元首/重審/比用/涉害/遙克/昴星/別責/八專/伏吟/返吟 + 三合局/連茹/間傳/三交…決定讀法側重 |
| 年命（本命/行年） | 問事人落點 | 看落點是否臨貴人/吉神/類神；**佐證用**，不當主體 |

## 四、九宗門與課體（讀法側重）

九宗門是**取三傳的九種法門**，也提示事情性質：

| 課體 | 怎麼起 | 讀法側重 |
|---|---|---|
| 賊克（元首/重審） | 一上剋下＝元首、一下賊上＝重審 | 事有明確衝突點，看上下神生剋 |
| 比用（知一） | 多剋，取與日干比（同陰陽）者 | 事分兩端而取一，主觀選擇 |
| 涉害 | 俱比/俱不比，比涉害深淺（見機/察微/綴瑕） | 事多牽連、複雜、遲疑，先難後易 |
| 遙克（蒿矢/彈射） | 上下無剋，日干與上神遙剋 | 遠方/間接之事，力弱難傷或隔物中人 |
| 昴星（虎視/冬蛇掩目） | 無剋無遙，四課全 | 妄想/空想未成、須隱忍待時 |
| 別責 | 四課不全（三課）無剋 | 事有缺失/依附他人 |
| 八專 | 干支同位（干寄宮=日支） | 事兩頭同一、不清、近親/重複 |
| 伏吟（自任/杜傳） | 天地盤相同 | 靜而不動、原地打轉、守舊 |
| 返吟（無依/無親） | 天地盤相沖 | 反覆、動盪、去而復返、事帶兩端 |

附加課體：**三合局**（曲直/炎上/稼穡/從革/潤下＝事情成局成形）、**三交**（三傳三合，交錯）、**連茹/進茹/退茹**（步步相連，進/退）、**間傳**（隔位而進，過程有間隙）、**斬關**、**勵德**（日德日祿發用）。課體是「事情長什麼樣」的標籤，用來選讀法角度，不直接等於吉凶。**「課體不吉，有一二吉神無補於課體之疵」——課體是底色。** 完整三十六課體主事見 `liuren-classics.md` 第七節。

## 七、四式綜合閱讀（六爻＋梅花＋六壬＋奇門）

四式同軸互參，**以問題為體，四式為用**，不硬拼一盤：

| 問題取向 | 主用 | 補用 |
|---|---|---|
| 具體成敗、時間點、細節（面試/官司/病情） | **六爻**（用神/世應/動變） | 六壬三傳定過程 |
| 快速判方向大勢、觸機、象義 | **梅花**（體用/互變） | 六爻/六壬核 |
| 過程人事、來意、人際牽連、結局 | **六壬**（四課三傳/天將/年命） | 六爻細節 |
| 方位、行動、時空調理、擇方 | **奇門**（九宮/八門/格局） | 六壬過程 |

**綜合步驟：**
1. **時間一致性**：四盤須同起於一個時刻（見 `event_cast.py` 的 `cross`）；日柱不一致（奇門子時換日） → 標低置信。
2. **同向加權**：四式結論方向一致 ＝ **高置信**，可直說。
3. **分歧處理**：見 `references/shared/verification.md` 的裁決順序；能講清楚以哪邊為主與理由。
4. **取象合流**：六爻六親六神、梅花上下互變、六壬天將神煞、奇門門星神干，**合起來取具體畫面**，不能只給氛圍。
5. **答法**：先直答（成/不成、何時），再補四式依據；定了調不自我反轉。

## 八、矛盾處理（本 skill 口徑，非古籍）

1. 先查**問句漂移**（一事一卦是前提；起卦想 A、解讀扯 B → 重鎖問句，不硬綜合）。
2. **分工**：成敗細節聽六爻；方向大勢聽梅花；過程/人事/來意/結局聽六壬；方位/行動聽奇門。
3. **純度加權**：手搖六爻 ＞ 報數梅花 ＞ 時間起卦（六壬/奇門同屬時間起課）；皆低純度 → 標低置信，不硬選邊。
4. **六壬與六爻同純度真矛盾** → **以六爻用神為主**（六爻最擅成敗細節），六壬三傳作過程/結局註腳、奇門作方位/行動註腳；寫分歧＋理由＋置信。
5. 分工後仍分歧 → 回**現實錨定**（使用者已知事實）再判，挑與事實相符者。
6. **不得**寫「矛盾未解」四字打發；要嘛裁決並說明，要嘛單獨一句「這條我看不準」。

## 九、輸出品質（引 `references/shared/output-quality.md`）

- **先直答**：第一句回答用戶問的那句。
- **每句掛依據**：用神/四課三傳/天將/年命/課體。
- **能給應期就給**：值日、沖、合、填實、沖墓之時；末傳所值干支月日。
- **取象具體**：天將＋神煞＋類神取畫面（「玄武臨財」＝財被暗取／不明流出），不給氛圍話。
- **結果怎麼講**：四式同向就直接肯定說；單一依據或孤證時，說明不確定的原因（如只有奇門表態、推導鏈長）。自然語氣（可能／也許）可用，只要不是換誰都成立。
- **大凶直言**：官鬼旺、身位/類神空墓，直說「不樂觀」，不粉飾。
- **外洩禁令**：不寫檔名/函數名/路徑；六壬術語（月將/天盤/三傳/天將）可用，必要時括號補白話。

## 十、終身課（問人輔助盤）

> 六壬主場是**問事**（一事一課、動態應機）；**終身課是輔助盤，權重低於八字紫微**。用途：補「一生動態人事、過程與結局」的視角，不翻轉主盤結論。

- **起課**：以**出生時刻**為正時（`liuren.py --lifetime --time "出生時刻" --gender 男/女`）。命主本命＝生年支；行年依性別逐年推（男丙寅順、女壬申逆），以 `--at-year` 指定參考年。
- **讀法**：整張課當「一生」讀——**干上＝自身本質與現況、支上＝家業/所依、三傳＝一生起伏**（初＝早年/發端、中＝中年/過程、末＝晚年/結局）；**本命為一生之應、行年為逐年之應**（流年看行年上神吉凶）。
- **要訣**：「**傳凶而年命有救，可轉禍為福**」；「三傳乃大概之象，**年命方切己**」。三傳全凶但年命臨吉神吉將 → 凶中帶救；年命被剋或入空墓 → 最切身的凶兆。
- **課體**：一生大局看課體（九宗門＋三十六課體，見 `liuren-classics.md` 第七節）；「課體不吉，一二吉神無補」。
- **交叉**：與八字（格局/用神）、紫微（命宮三方）對照——同向加權，分歧則**以主盤（八字紫微）為準**，六壬終身課作「動態/結局」註腳。
- **紅線**：六壬**問事**結論不得用終身課當主要依據；終身課也不得改寫八字紫微的格局定論。
