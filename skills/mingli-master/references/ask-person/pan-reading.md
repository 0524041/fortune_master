# 命盤解盤指南（融合主軸）

> 問人（八字＋紫微）的統一解盤思路。**紫微定象、八字定勢；南派（三合）為主、北派（四化）為輔。**
> **三方四正是核心**；北派飛星只用來追因果與應期，不與廟旺、凶星重複加碼。
> 盤面數字照抄程式（讀法見 `bazi.md`／`ziwei.md`）；怎麼說見 `references/shared/output-quality.md`。

## 一、解盤主軸（八步）

```
定盤 → 定調 → 定體用 → 量力量 → 定人事 → 追因果 → 定時間 → 交叉直答
先驗    命宮/日主  問題太極  廟旺/強弱  十二宮/十神  四化(輔)  大限/大運  八字×紫微
```

1. **定盤（先驗再斷）**：四驗見 `shared/verification.md`；再用已知的人生事件對照。時辰存疑先校盤，別硬斷。
2. **定調（找主角）**：
   - 主：**紫微命宮**主星組合（＋身宮）定氣質；空宮借對宮主星。
   - 輔：**八字日主＋月令**定體性（子平：用神專求月令）。
3. **定體用（問題太極）**：問什麼，就以那一宮為太極，拉它的三方四正。八字以**月令為綱**。
4. **量力量**：
   - 八字：`day_strength` 身強弱＋`yongshen` 用忌＋`tiaohou` 調候。
   - 八字進階：三得標籤（得令／透干／通根／黨眾寡，與分數並陳）＋十神組合（`shishen_combo.md`）＋從格專旺（`waige.md`）；大運流年作用見 `suiyun.md`。
   - 紫微：星曜**廟旺利陷**＋**四化**（生年祿權科忌落宮）。
   - 紫微進階：輔煞夾宮四化（`fusha.md`）；火貪鈴貪須五件套齊全，不單取貪＋火。
   - 判讀輕重：**本宮最重 → 對宮其次 → 三合再次**。
5. **定人事**：十二宮（誰、什麼領域）＋十神（什麼性質的力）。
6. **追因果（可選，北派為輔）**：生年四化 → 大限宮干 → 流年干。自化／來因宮**只參考**；不要「忌沖＋凶星＋自化」重複加碼。
7. **定時間**：八字**大運**定節奏；紫微**大限→流年**定節點；同年兩套疊到＝加權。**十年運／大運轉折／流年題必看輔助盤**：六壬行年（逐年之應）＋奇門大限宮（見 `aux-charts.md`）。
8. **交叉直答**：同向＝信度高；矛盾＝先查時辰，再判斷是不是不同層次（八字講力量、紫微講領域）。財運題先看 `cast.py` 語義初判（同向／分歧／單邊／缺料），LLM 只做覆核。**總覽題一律跑 `person_cast.py`**（主盤＋六壬終身課＋奇門終身盤），讀法見 `aux-charts.md` 第四節（主盤為準、輔助補維度）；最後給**型態＋時窗＋該做/避開**，或然判斷帶置信標記。

## 二、三方四正速查

規則：任一宮的**三方**＝本宮＋兩個三合宮（隔四宮）；**四正**＝再加對宮（隔六宮）。常用六組：

| 太極宮 | 三方（三合） | 對宮 | 這組在看 |
|---|---|---|---|
| 命宮 | 財帛、官祿 | 遷移 | 自我＋事業財富＋社會舞台 |
| 財帛 | 命宮、官祿 | 福德 | 賺錢方式＋能力＋精神面 |
| 官祿 | 命宮、財帛 | 夫妻 | 事業＋本命＋財務＋夥伴/伴侶 |
| 夫妻 | 遷移、福德 | 官祿 | 感情＋外緣＋精神契合＋工作 |
| 遷移 | 福德、夫妻 | 命宮 | 外出發展＋福分＋伴侶 |
| 福德 | 夫妻、遷移 | 財帛 | 精神滿足＋感情＋外緣＋錢 |

（其餘：兄弟↔疾厄/田宅/僕役；子女↔僕役/父母/田宅；疾厄↔田宅/兄弟/父母；僕役↔父母/子女/兄弟；田宅↔兄弟/疾厄/子女；父母↔子女/僕役/疾厄。八字側用「十神配置」對應同樣的人事。）

## 五、四化讀法（北派為輔）

- **生年四化**（年干固定）：祿＝資源／和順；權＝掌控／責任；科＝名聲／貴人；**忌＝掛心與阻力（最重，落哪宮哪領域是課題）**。
- **自化**（宮干飛出／飛入）：離心＝洩、向心＝聚 → **參考**。
- **來因宮**：生年干所在宮＝起心動念的源頭 → **參考**。
- **原則**：四化只用來追「為什麼、何時」，不與廟旺／凶星重複加碼；一個判斷一條依據。

## 七、時間軸敘事

- 節奏：**大限／大運**（十年氣候）→ **流年**（當年天氣）→ 必要才流月。
- 一句話公式：**時間＋宮位/干支依據＋後果＋動作**。
- 分界注意：八字一律**立春**；紫微預設**正月初一**（`--horoscope-divide exact` 改立春），年初/年末會差一輪。
