# 起卦前引導 (所有「問事／占卜」通用)

> 適用於**一切起卦**：六爻、梅花、六壬，以及未來任何起卦法。
> **算命（八字／紫微）不需要這一步**——那是排盤，只需收料（生日時分/城市）；只有「問一件事、要起卦」才要走這裡。
>
> **不要急著起卦。** 問題不清楚就起卦，卦象多半對不上問題。這一步做足，解卦才準。

## 一、先判斷「適不適合起卦」

**明確議題**（可直接起卦）：具體人事物、有明確選項或時間範圍、能鎖定用神。
例：「我下個月該不該換到 A 公司？」「這段感情能不能走到結婚？」

**不明確議題**（先引導，勿起卦）：
- 含糊問法：「幫我看看運勢」「大師給點建議」
- 多主題混雜：「事業和感情都想問」
- 問總體大盤：「明年股市如何？」（卦取不到個人用神）
- 缺乏背景：看不到當事人處境與選項
- 明事體但缺領域（「明天辦事順不順」不說何事）：**可起**，走 `yongshen.md` 決策樹第 2 條（世爻為用）＋標低置信，不算違規起卦。

## 二、引導方式（一次問 1-2 題，別連環砲）

1. 「您主要想問哪一方面？感情／事業／財運／健康／考試／失物？」
2. 「具體對象或選項是什麼？（換 A 還是 B／跟某人是否適合）」
3. 「目前處境與已知事實？」（供現實錨定）
4. 問大盤 → 引導改問：「您個人投資這個項目的財運如何？」

**可解卦標準**：能明確鎖定用神（六爻查 `yongshen.md` 決策樹，含世爻為用 fallback）、知道當事人狀態、問題聚焦單一議題。達標才起卦；過引導檢查點（見 `liuyao.md` 第五節三道門）才算達標。

**順便確認題型**（答法不同）：成敗（能不能成）／時機（何時）／對方心意（他怎麼想）／取象（會遇到什麼、有哪些細節）／尋物（東西在哪）。同一件事問不同的點，卦的讀法就不一樣。

## 三、疑難問法（照這樣引導）

**投資／股市（最常見）**
- 把「**它**會不會漲」改問成「**我**投資這檔的財運／該不該進出／什麼時機進出」——這樣才取得到用神（六爻：妻財＝財、世爻＝你；梅花：體＝你、用＝此事）。
- 若使用者堅持只問「那支股票會不會漲、何時漲」（與己無關的公共預測）→ 說明六爻取不到**你的**用神，建議改問個人標的。
- 這是**取用神的技術問題**，不是勸退；能用個人用神答的就直接答。問個人財運（不需起卦）走 `references/ask-person/caiyun.md`。

**其他易失焦**：多主題混問（先拆成一題）；含糊求建議（先問領域＋具體選項）；失物（先問物象特徵與最後出現時間）。

## 四、選哪一種（六爻 vs 梅花 vs 六壬）

| 需求 | 用 |
|---|---|
| 具體成敗、時間點、細節（工作面試、官司、病情） | **六爻**（用神/六親六神/世應空破） |
| 快速判方向大勢、觸機、象義（此刻這件事的走向） | **梅花**（體用生剋，起卦法輕） |
| 過程人事、方位、來意、人際牽連、結局 | **六壬**（四課三傳、天將、年命） |
| 想一次看全 | **四式合盤** `event_cast.py`（同刻出四盤） |

多法並用互參：結論一致＝信心高；分歧＝回到現實錨定再判（見 `references/shared/verification.md`）。

## 五、起卦紀律與時間依據

- **前提是心動**：靜心、誠心、專注一念，**一次只問一件事**；同一事不反覆起卦（初筮告，再三瀆，瀆則不告）。**不疑不卜、不戲占；一天不超過三卦**（倪師）。
- **依據優先序**：心動（前提）＞ 手搖銅錢（六爻首選）＞ 外應／報數（梅花最靈）＞ 當下時間（通用、客觀、不可造假）。
  - 六爻：`--coins` 回報手搖結果；沒銅錢時電腦代搖（預設）或報數皆可。**時間決定月建／日辰（旺衰背景）**。
  - 梅花：`--time`（時間起卦，預設）／`--numbers`（報數）／`--random`。
  - 六壬：`--time`（月將加占時，時間起課）；`--birth`／`--gender` 可選入本命／行年。
- **時間預設系統現在**：現在問＝現在起卦；**農曆（年支／月／日／時支）與四柱干支、日空亡、六神、月將全由程式換算，勿心算**。不用問使用者；只有他提供**實際起卦時刻**才用 `--time`。
- **用當地時鐘時間**，不做真太陽時校正（真太陽時是八字排盤用的）；貼近子時（23:00–01:00）或整點交界時，記下精確分鐘以免跨日。六壬月將逢中氣交界亦記精確分鐘。
- 起卦後：六爻讀 `liuyao.md`＋`yongshen.md`；梅花讀 `meihua.md`；六壬讀 `liuren.md`；卦辭/象傳一律採 `data/hexagrams_64.json`，勿編造。
