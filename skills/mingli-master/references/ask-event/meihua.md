# 梅花易數

> 起卦與排卦由 `scripts/yijing/meihua.py` 產生，**不可心算**；本檔只講怎麼讀。

## 一、起卦法

> 原理：**心動即占**——起念那一刻的時間氣場就是座標。時間起卦是梅花原生方法；起卦當下的**農曆**年支＋月＋日＋時支由程式換算（勿心算）。
> **先天之數**＝以數起卦（時間／數字／聲音／物數）；**後天之數**＝以卦起數（見物起卦）。外應參斷（心易三要＋十應）與原書要訣見 `principles.md`。

| 方式 | 指令 | 說明 |
|---|---|---|
| 時間起卦 | `meihua.py --time "2026-08-01 10:30"` | 以農曆年支數＋月＋日取上卦，再＋時支數取下卦與動爻 |
| 數字起卦 | `meihua.py --numbers 17 23`（或三數 `17 23 5`） | 兩數取上下卦，和或第三數取動爻 |
| 隨機起卦 | `meihua.py --random` | 電腦代數，求「隨機觸機」 |

**時間起卦公式**（程式內定，勿心算）：
- 上卦 =（年支數＋農曆月＋農曆日）mod 8（0 取 8）
- 下卦 =（年支數＋農曆月＋農曆日＋時支數）mod 8
- 動爻 =（年支數＋農曆月＋農曆日＋時支數）mod 6（0 取 6）
- 八卦先天數：乾1 兌2 離3 震4 巽5 坎6 艮7 坤8；年支子1…亥12。

## 二、讀卦三步

1. **本卦**＝當下處境（上卦＋下卦）。先看卦名與卦義（可對照 `data/hexagrams_64.json` 的原文，勿編造）。
2. **互卦**＝事情內在過程／隱情（本卦 2·3·4 爻為下互、3·4·5 爻為上互）。
3. **變卦**＝事情結果／趨勢（動爻變後的卦）。

> 盤面（`meihua.py` 輸出）已附本卦／互卦／變卦的**卦辭、象傳、諸事**（引自 `data/hexagrams_64.json`），直接引用，勿背誦、勿編造。
> 互卦與變卦另標明**上下卦五行**，供生剋推算。

## 三、體用生剋（梅花核心）

- **動爻所在的卦為「用」，另一卦為「體」**（體＝自己/主體，用＝所問之事/對方）。
> 原文《體用總訣》：「凡上下二卦**無動爻者為體，有動爻者為用；體卦為主，用卦為事，互卦為事之中應，變卦為事之末應**。」
- 五行：乾兌金、離火、震巽木、坎水、艮坤土。
- 判吉凶：
  | 關係 | 意義 |
  |---|---|
  | 用生體 | **吉**（外來助力） |
  | 體剋用 | **吉**（我能掌控） |
  | 體用比和 | **吉**（同氣相助） |
  | 體生用 | 洩／耗（付出、被牽走） |
  | 用剋體 | **凶**（受制、受損） |
- **生剋疊加（盤面已算好，勿心算）**：
  - **變卦疊加（結果）**：取變卦中「原用卦變化後之卦」五行 vs 體 → 結果趨勢（例：變卦生體＝過程雖難但結果助我）。
  - **互卦疊加（過程）**：取互卦中與用同側之卦五行 vs 體 → 過程參考。
  - 三者合看：本卦看現況、互卦看過程、變卦看結果；結果與現況同向＝信心高，分歧＝過程中生變。
- **卦氣旺衰**：體宜旺——春震巽木旺、夏離火旺、秋乾兌金旺、冬坎水旺、四季月坤艮土旺；體衰則力弱。
- 原文：「體用之間，比和則吉；**用吉變凶者，先吉而後凶；用凶變吉者，先凶而後吉**。」

## 五、各領域該回答什麼

梅花適合「快速判方向與大勢」，回答時先給方向，再補體用依據：
- **感情**：這段關係的走向（聚/散/卡）→ 體用 + 互變。
- **事業/工作**：成不成、順不順 → 體用 + 變卦。
- **財運（起卦）**：進財時機與方向 → 體用 + 變卦（不替人下單）。
- **健康**：走向輕重 → 體用 + 變卦。
- **尋物/尋人**：找不找得到 → 體用 + 應期方位。
- **日常事（約會／聚餐／出門）**：順不順、會遇到什麼 → 以象取用：上下卦、互變、五行生剋、卦辭，給**具體畫面**（不給氛圍）。
- **兩法交叉**：六爻＋梅花一起用時，同向＝明說「兩法一致、可信度較高」；分歧＝說「以哪個為主、為什麼」。不要各寫一段就交卷。
